# Deeplink

Cocos Creator 3.8.x build-plugin extension that wires up Android App Links
and iOS Universal Links / custom URL schemes, plus a small TypeScript
runtime API for receiving deep-link URLs at cold start and while the app is
running.

Full documentation:

- English: [doc/en/index.md](./doc/en/index.md) ([Android](./doc/en/android/index.md) · [iOS](./doc/en/ios/index.md))
- 中文: [doc/zh/index.md](./doc/zh/index.md) ([Android](./doc/zh/android/index.md) · [iOS](./doc/zh/ios/index.md))

See the repository root [README.md](../../README.md) for installation and
the runnable demo.
